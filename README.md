A structured collection of interactive Jupyter Notebooks documenting a progressive learning path through core Python programming, data manipulation, and fundamental concepts in artificial intelligence and supervised machine learning. 

This repository serves as a code-first foundation for predictive modeling and data science, moving systematically from core programming syntax to numerical processing and classification tasks.

## 🗂️ Repository Structure

The curriculum is divided into three core phases:

### Phase 1: Core Python Mechanics
Focuses on the essential syntax and control structures required for data manipulation.
* `AIML 01 - Introduction to Python - Variables and Data Types.ipynb`
* `AIML 02 - Introduction to Python - Lists in Python.ipynb`
* `AIML 03 - Introduction to Python - Functions, Methods.ipynb`
* `AIML 03 - Introduction to Python - Python Conditions and Loops.ipynb`

### Phase 2: Numerical Processing
Transitions from standard library data structures to high-performance array manipulation.
* `AIML 04 - Introduction to Python - NumPy.ipynb`

### Phase 3: Artificial Intelligence & Machine Learning
Applies the programming foundations to theoretical and practical data science workflows.
* `AIML 00 - Data Science.ipynb`
* `AIML 00 - Supervised Learning - Classification.ipynb`

*(Note: Files are currently grouped conceptually. For the best experience, progress from Phase 1 through Phase 3).*

## 🚀 Getting Started

To interact with these notebooks:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/aiml-python-foundations.git
   ```
2. **Launch Jupyter Notebook / JupyterLab:**
   Navigate to the directory and run:
   ```bash
   jupyter notebook
   ```
3. **Alternatively, use Google Colab:**
   You can easily upload these `.ipynb` files to [Google Colab](https://colab.research.google.com/) to run them in the cloud without local environment setup.

## 🛠️ Tech Stack & Prerequisites
* **Language:** Python 3.x
* **Core Libraries:** NumPy
* **Environment:** Jupyter Notebook / Google Colab
* **Prerequisites:** Basic understanding of logical problem-solving. No prior Python experience is strictly required for Phase 1.
